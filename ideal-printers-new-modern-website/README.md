# Ideal Printers & Packages — Modern Website Prototype

Original multi-page prototype for **Ideal Printers & Packages**.  
This is a new design (not based on Deluxe Printing / dlxprint.com SEO, tags, or structure).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Home — full-bleed hero, smooth carousel, capabilities |
| `our-studio.html` | Studio story & pillars |
| `craft-line.html` | Service lanes (packaging, identity, spatial) |
| `showcase.html` | Gallery + carousel |
| `connect.html` | Contact / project brief form |

## Brand

- Logo: `assets/logo.png`
- Orange `#F28C38` · Green `#409B7A` · Slate `#3F4B5B`

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

Then visit the local URL shown in the terminal.

## Notes

- No Google Analytics / Tag Manager / third-party SEO scrapes from other brands.
- Images are Unsplash placeholders for the prototype; replace with your photography before launch.
- Contact details use example placeholders — update before production.
